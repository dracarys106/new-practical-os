# Practical 01 — Demonstration of OS Functions Using an OS Simulator

[Back to Index](../README.md)

## Practical Question

**Demonstration of various Operating System functions using OS Simulator.**

## Aim

To study and demonstrate the basic functions of an operating system with the help of the OS simulator available in the laboratory.

## Requirements

- OS simulator specified by the instructor/laboratory.
- Computer with a web browser or the simulator application, as applicable.

## Procedure

1. Open the OS simulator provided by the instructor.
2. Read the simulator's instructions and identify its available modules.
3. Demonstrate the OS functions that the simulator supports. Common topics include:
   - Process management: process creation, process states and scheduling.
   - CPU scheduling: FCFS, SJF and priority scheduling, if available.
   - Memory management: allocation and deallocation.
   - File management: creating, reading, writing and deleting files.
   - Device/I/O management: handling input and output requests.
4. Change the input values where the simulator permits it.
5. Run the simulation and observe the resulting process sequence, memory layout, or other displayed result.
6. Record the actual screenshots and observations from your lab simulator.

## Observation

Fill in the following table using the simulator you actually used.

| Function demonstrated | Input / action | Observation |
|---|---|---|
| Process management | Add or create a process | Write the observed process state/sequence |
| CPU scheduling | Run an available scheduling algorithm | Write the observed execution order |
| Memory management | Allocate/deallocate memory | Write the observed memory status |
| File management | Perform a file operation | Write the observed result |
| I/O management | Submit an I/O operation | Write the observed result |

## Result

Various operating system functions were demonstrated and studied using the OS simulator.

## Important Details

- The question does not specify the name or version of the simulator. Do not claim that a particular simulator was used unless it was actually used in your lab.
- Simulator screens and exact steps vary. Add your own lab screenshots and actual observations before submission.
- This practical is a simulator demonstration; Python code is not required by the question.
